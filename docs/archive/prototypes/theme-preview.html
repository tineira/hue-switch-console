How the set was chosen

  • One of each character. Current live themes have three near-black ambers (Ember, Graphite, Night) and three pale blues (Snow, Sky, Mist). The new set keeps one of each look.
  • Names people recognise. Tokyo Night, Catppuccin, Gruvbox, Nord and the others are well-known editor palettes, and Omarchy users get the same look as their desktop.
  • Readable first. Muted text and the status pill colours are nudged lighter (dark themes) or darker (light ones), just enough to pass 4.5:1; the card lists which. Hand-picked changes from Omarchy (mostly accents that were too pale for a button) are marked "adjusted"; hover the card for details.
  • Left out from Omarchy: Hackerman (Matrix already covers it), Vantablack, White, Solitude and Last Horizon (grey accents, so buttons and state colours blur together), Lumon (red, green and yellow are all blue, so Offline looks like Online), Miasma (low contrast), Lupine, Retro-82 and Ethereal (few would miss them; easy to add later).
